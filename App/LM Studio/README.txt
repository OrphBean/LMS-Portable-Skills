Place the LM Studio app here so that this file exists:

    App\LM Studio\LM Studio.exe

How to get it:
  1. Download the LM Studio Windows installer from https://lmstudio.ai/download
  2. Run the installer and choose (or extract to) this "App\LM Studio" folder,
     OR install normally and let install.bat copy it from your install location.

The contents of this folder (the .exe, resources, locales, DLLs, *.pak) are
kept OUT of git on purpose - they are large and version-specific. Only this
placeholder is tracked.
